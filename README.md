## Tungkol sa Website

Ito ang simpleng website ng kampanya ayon sa **Milestone 3 — G. Sariling Simpleng Website**.

### Mga Pahina
| Pahina | Nilalaman |
|--------|-----------|
| **Home** (`index.html`) | Pangalan ng kampanya, slogan, pangunahing mensahe, at CTA |
| **Tungkol** (`about.html`) | Isyu, target audience, layunin, mensahe, at mga kasapi |
| **Gabay** (`guides.html`) | Praktikal na tip at listahan ng campaign materials |
| **Sanggunian** (`references.html`) | Mga mapagkakatiwalaang source at ebidensiya |
| **Makilahok** (`join.html`) | Pledge form / commitment activity |

### Slogan
**Mag-isip Bago Mag-Post: Matalinong Paggamit, Ligtas na Kinabukasan**

### Call to Action
Simulan ang pagbabago ngayon: Mag-isip bago mag-click, huwag magbahagi ng sensitibong impormasyon, at suriin muna ang katotohanan bago maniwala o magpasa ng balita.

---

## Paano Buksan

1. I-download o i-copy ang buong folder `responsible-social-media-campaign`.
2. Buksan ang `index.html` sa browser (Chrome, Edge, Firefox, o Safari).
3. Hindi kailangan ng internet para sa basic viewing (maliban sa mga external link sa Sanggunian).

### Opsiyonal: I-host online
- **Google Sites**: Kopyahin ang nilalaman at i-paste sa Google Sites.
- **GitHub Pages / Netlify / Vercel**: I-upload ang folder para sa free public link.
- **Loophole / local tunnel**: Kung may server setup.

---

## Privacy Reminder
- Walang personal na contact details o larawan ng mga estudyante.
- Ang pledge form ay lokal lang (hindi nagsesave sa server).
- Sundin ang patakaran ng paaralan bago gawing pampubliko.
